# Atlas Platform Roadmap

## Purpose

This document defines the remaining work required to complete the first
functional version of the Atlas platform.

It is not a design document.

It is the implementation roadmap.

---

# Phase 1 — Submission

- [ ] Submission Service complete
- [ ] CLI complete
- [ ] GitHub client complete
- [ ] Second client successfully submits an artifact

---

# Phase 2 — Validation

- [ ] Structural validator complete
- [ ] Semantic review workflow complete
- [ ] Structural and semantic validation separated

---

# Phase 3 — Materialization

- [ ] Artifact materialization
- [ ] Judgment materialization
- [ ] Contradiction materialization

---

# Phase 4 — Repository Integration

- [ ] Git workflow complete
- [ ] Pull Request workflow complete
- [ ] Merge workflow complete

---

# Phase 5 — End-to-End

Complete successful execution of the following workflow:

- [ ] Submission
- [ ] Structural validation
- [ ] Semantic review
- [ ] Materialization
- [ ] Repository update

---

# Version 1

Atlas Platform Version 1 is complete when every item above has been
implemented and demonstrated in practice.
